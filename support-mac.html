GridPlayer for Mac 技术支持

Support and frequently asked questions

联系支持

如需报告问题、提供反馈或提出功能建议，请发送邮件：

support@gridnet.top

也可以前往 GitHub Issues 提交问题，我们会尽快回复。

For support, bug reports, or feature requests, email support@gridnet.top. English messages are welcome.

系统要求

  • macOS 15.0 或更高版本；
  • 支持 Apple Silicon 与 Intel Mac；
  • 连接个人服务器时，需要可访问的 Navidrome 或兼容 Subsonic 服务。

常见问题

找不到本地音乐

请在“音乐源”中重新选择音乐根目录，并确认 macOS 仍允许 GridPlayer 访问该目录。GridPlayer 只读取用户选择的目录，不会修改或删除原始音乐文件。

个人音乐服务器无法连接

请检查服务器地址、用户名和密码，并优先使用 HTTPS。服务器需要能从当前 Mac 所在的网络访问；公网地址不允许使用明文 HTTP。

封面或歌词没有更新

可以在“存储管理”中清除封面或歌词缓存。GridPlayer 会在下次需要时重新获取相关内容。

如何完全移除本地数据

先在应用中移除音乐源并清除缓存。卸载应用后，还可以删除 GridPlayer 的 Application Support、Caches 数据和对应的 macOS 钥匙串项目。

提交问题时请提供

  • macOS 版本和 Mac 芯片类型；
  • GridPlayer 版本与构建号；
  • 问题出现前的操作步骤；
  • 已经隐去服务器地址、用户名、文件路径等个人信息的截图或错误信息。

请不要发送音乐服务器密码、访问令牌或未经脱敏的资料库数据。
