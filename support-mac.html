System Requirements

  • macOS 15.0 or later;
  • Apple Silicon and Intel Macs are supported;
  • A reachable Navidrome or compatible Subsonic service is required only when you connect a personal music server.

Supported Music Sources

  • One or more local music folders selected through the macOS file picker;
  • Personal Navidrome servers;
  • Compatible Subsonic servers.

GridPlayer does not provide music or a developer-hosted music server.

Frequently Asked Questions

GridPlayer cannot find my local music

Open Music Sources and select the root music folder again. Confirm that macOS still allows GridPlayer to access it. GridPlayer reads only folders you select and does not modify or delete original music files.

My personal music server will not connect

Check the server address, username, and password, and prefer HTTPS. The server must be reachable from this Mac. Plain HTTP is allowed only for local or private-network addresses, and GridPlayer warns before connecting without encryption.

Artwork or lyrics have not refreshed

Clear the artwork or lyrics cache from Storage. GridPlayer retrieves rebuildable content again the next time it is needed.

Apple Music artist artwork matching is unavailable

Artist artwork matching is optional and off by default. Enable it from Library Settings, then allow Media & Apple Music access when prompted. This feature sends limited artist, song, album, or manually entered search terms to the Apple Music catalog; it never uploads music files or server credentials.

How do I remove local app data?

Remove music sources and clear caches in the app. You can also use the app’s delete-all-data option. After uninstalling, any remaining GridPlayer Application Support, Caches, and corresponding macOS Keychain items can be removed manually. These actions do not delete original music files.

What to Include in a Report

  • Your macOS version and Mac chip type;
  • The GridPlayer version and build number;
  • The steps immediately before the issue occurred;
  • A screenshot or error message with server addresses, usernames, file paths, and other personal information removed.

Never send a music-server password, access token, or unredacted library data.

常见问题

找不到本地音乐

请打开“音乐源”，重新选择音乐根目录，并确认 macOS 仍允许 GridPlayer 访问该目录。GridPlayer 只读取用户选择的目录，不会修改或删除原始音乐文件。

个人音乐服务器无法连接

请检查服务器地址、用户名和密码，并优先使用 HTTPS。服务器必须能从当前 Mac 访问。只有本地或私有网络地址可以使用明文 HTTP，并且 GridPlayer 会在未加密连接前显示警告。

封面或歌词没有更新

可以在“存储管理”中清除封面或歌词缓存。GridPlayer 会在下次需要时重新获取这些可重建内容。

Apple Music 艺术家头像匹配不可用

艺术家头像匹配是默认关闭的可选功能。请在“资料库设置”中开启，并在提示时允许媒体与 Apple Music 访问。该功能只会向 Apple Music 目录发送有限的艺术家、歌曲、专辑或手动输入的搜索词，不会上传音乐文件或服务器凭据。

如何完全移除本地数据

请在应用中移除音乐源并清除缓存，也可以使用应用内“删除全部应用数据”功能。卸载后，还可以手动删除 GridPlayer 的 Application Support、Caches 数据和对应的 macOS 钥匙串项目。这些操作不会删除原始音乐文件。

提交问题时请提供

  • macOS 版本和 Mac 芯片类型；
  • GridPlayer 版本与构建号；
  • 问题出现前的操作步骤；
  • 已经隐去服务器地址、用户名、文件路径等个人信息的截图或错误信息。

请不要发送音乐服务器密码、访问令牌或未经脱敏的资料库数据。
